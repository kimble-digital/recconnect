The round photo uses a CSS circle mask, which Gmail, Apple Mail and Outlook on the web honour, but the classic Windows Outlook app may show it as a square. Custom brand fonts don't render in email, so the signature uses Arial by design.

How to add it

  1. Gmail: click Copy signature, then Settings (gear) → See all settings → General → Signature → Create new, and paste (Ctrl/Cmd V).
  2. Outlook (new / web): Settings → Mail → Compose and reply → Signature, and paste.
  3. Apple Mail: Mail → Settings → Signatures, untick "Match message font", and paste.
  4. If a client strips the formatting, use Copy HTML code and paste into its "edit HTML / source" option instead.
